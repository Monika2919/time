# time

Time Series Forecasting: Dense Baseline vs LSTM with Attention

Project Overview
This project focuses on time series forecasting using neural network models. The main goal is to compare a simple Dense (feed-forward) baseline model with a more complex LSTM model enhanced with an attention mechanism, and to evaluate whether the added complexity leads to better forecasting performance.
Rather than assuming that advanced models always perform better, this study examines how model performance depends on data characteristics such as smoothness, seasonality, and sequence length.

Dataset Description
The primary experiments were conducted using a synthetic univariate time series.
The dataset was generated by combining:
•	A linear trend component
•	A sinusoidal seasonal pattern
•	Random Gaussian noise
This controlled setup makes it easier to interpret model behavior while still reflecting common real-world time series properties. The same code structure can also be applied to real datasets such as energy consumption or ETTh with minimal modification.
Data Preprocessing
Before training, the following preprocessing steps were applied:
•	All values were scaled using Min-Max normalization to the range [0, 1]
•	A fixed look-back window of 30 time steps was used
•	Each input sample consists of 30 consecutive observations, with the target being the next time step
•	The data was split chronologically:
o	80% for training
o	20% for testing
This approach ensures that future information is not leaked into the training process.

Models Implemented
Dense Baseline Model
The Dense baseline model uses a simple feed-forward architecture. The input sequence is flattened and passed through two hidden Dense layers with ReLU activation, followed by a linear output layer.
This model serves as a reference baseline, allowing performance comparisons against more complex architectures.
________________________________________
LSTM with Attention
The second model consists of an LSTM layer followed by a self-attention mechanism. The LSTM is responsible for learning temporal dependencies, while the attention layer is intended to assign different importance weights to time steps within the sequence.
The motivation behind this model is to evaluate whether attention can improve forecasting accuracy by focusing on more relevant parts of the input sequence.
________________________________________
Hyperparameter Tuning
Hyperparameter tuning was performed using a manual grid search, with validation Mean Squared Error (MSE) as the optimization objective.
The following parameters were explored:
•	Number of LSTM units
•	Learning rate
•	Batch size
•	Number of training epochs
Early stopping and learning-rate reduction were applied to prevent overfitting and improve training stability. The final model configuration was selected based on the lowest validation MSE.
________________________________________
Evaluation Metrics
Model performance on the test set was evaluated using:
•	RMSE (Root Mean Squared Error)
•	MAE (Mean Absolute Error)
•	MAPE (Mean Absolute Percentage Error)
All metrics were computed after reversing the normalization step to ensure interpretability.
________________________________________
Final Results
Metric	Dense Baseline	Attention LSTM
RMSE	0.55	1.77
MAE	0.44	1.53
MAPE	3.24%	10.89%
The Dense baseline model consistently achieved lower error across all metrics.
________________________________________
Discussion and Observations
Although the LSTM with attention is more expressive, it did not outperform the Dense baseline in this setting. This can be attributed to several factors:
•	The time series exhibits relatively smooth and regular patterns
•	The look-back window is short, reducing the benefit of explicit attention weighting
•	The attention mechanism introduces additional parameters, increasing the risk of overfitting
These results highlight that simpler models can be more effective when the data structure does not require complex temporal representations.

Conclusion
This project demonstrates that increased model complexity does not automatically guarantee better forecasting performance. In scenarios with structured and low-complexity time series data, simpler baseline models can outperform more advanced architectures such as LSTM with attention.
